MyLibrary workflow wiki

Where this tool sits in a paper workflow, and the four routines it is built around. Diagrams render locally with Mermaid — no network needed.

Feature status

  • ready Local install, everything under data/ in this clone (./mylibrary run)
  • ready Add by title / URL / DOI / arXiv ID, or bulk-import a Zotero collection offline
  • ready Timeline cards with a figure carousel (swipe / arrows / dots / click for lightbox)
  • ready PDF reader and study view with shared text annotations, tags, and a floating reading window
  • ready Annotation context API for external AI agents (/api/papers/{id}/annotations/context)
  • optional Telegram bot for adding papers from a phone (needs a BotFather token)
  • planned Region-selection annotations on figures inside the PDF reader

1 · Position: which layer of the literature stack

MyLibrary does not replace a reference manager. It fills the layer a reference manager is weakest at: coming back to papers, looking at their figures, and re-reading them. Zotero stays the storage and BibTeX backend.

2 · Routine A — getting papers in (three entry points)

All three entry points land in the same timeline. Paywalled papers reuse the PDF already stored by Zotero, so they get figures too.

4 · Routine C — reading and annotating

Use the built-in reader when the highlights should end up in the library; open the file in a native reader when you just want smooth scrolling.

5 · Routine D — handing context to an AI agent

Annotations are not a dead end. A stable JSON endpoint exposes the thread for an external agent, which can reply back into it as assistant.

sequenceDiagram
  participant R as Reader
  participant M as MyLibrary
  participant A as External agent
  R->>M: select text → 添加批注 (add annotation)
  R->>M: 复制给 AI (copy context)
  M-->>R: structured JSON thread
  A->>M: GET /api/papers/{id}/annotations/context
  M-->>A: paper + annotations + instructions
  A->>M: POST .../annotations/{id}/replies (role=assistant)
  M-->>R: reply appears in the sidebar thread

Maintenance notes

  • This page lives in src/mylibrary/web/templates/wiki.html — edit it to describe your own workflow.
  • Mermaid is vendored at static/vendor/mermaid/mermaid.min.js, so the page works offline.
  • Zotero bulk import is zotero_import.py; run it with --list to see your collections.
  • The web UI has no authentication and binds to 127.0.0.1. Keep it that way, or put it behind an authenticated proxy.

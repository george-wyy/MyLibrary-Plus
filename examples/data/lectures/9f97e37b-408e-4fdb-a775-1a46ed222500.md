# Attention Is All You Need — Study Notes

## Why this paper matters

Before this paper, the best sequence-to-sequence models (machine translation,
language modeling) were built on recurrent networks — LSTMs and GRUs — often
wrapped in an attention mechanism as an add-on. Vaswani et al. throw the
recurrence away entirely and show that attention alone, stacked into an
encoder-decoder, is enough to reach state-of-the-art translation quality while
training in a fraction of the wall-clock time, because every position in a
sequence can now be processed in parallel instead of one step at a time.

## The core idea

The Transformer replaces recurrence with [[self-attention]]: every token
directly attends to every other token in the sequence in a single step, so
the "distance" between any two positions is $O(1)$ instead of $O(n)$ as it
is in an RNN. This is what removes the sequential bottleneck.

## Scaled Dot-Product Attention

The attention function used throughout the model is:

$$
\mathrm{Attention}(Q, K, V) = \mathrm{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
$$

Queries $Q$, keys $K$, and values $V$ are all linear projections of the input.
The $\sqrt{d_k}$ scaling factor keeps the dot products from growing too large
in magnitude as $d_k$ increases, which would otherwise push the softmax into
regions with vanishingly small gradients.

## Multi-Head Attention

Rather than computing a single attention function, the model projects $Q$,
$K$, $V$ into $h$ different subspaces and runs [[self-attention]] in
parallel in each one (8 heads in the base model), then concatenates and
projects the results back down. Each head can specialize — some heads end up
tracking syntactic dependencies, others more local relationships.

## Positional Encoding

Self-attention has no built-in notion of token order, so the model adds a
[[positional-encoding]] vector to each input embedding before the first
layer, using fixed sinusoids of different frequencies:

$$
PE_{(pos,\,2i)} = \sin\!\left(pos / 10000^{2i/d_{model}}\right)
$$

## Summary

- Replaces recurrence and convolution with attention alone; encoder and
  decoder are each stacks of self-attention + feed-forward sublayers.
- Scaled dot-product attention: $\mathrm{softmax}(QK^\top/\sqrt{d_k})V$.
- Multi-head attention lets the model attend to information from different
  representation subspaces at different positions simultaneously.
- Sinusoidal [[positional-encoding]] injects order information without
  adding recurrence.
- Full parallelization over sequence positions during training is the main
  practical win — dramatically less training time than RNN-based models for
  comparable or better BLEU scores.
